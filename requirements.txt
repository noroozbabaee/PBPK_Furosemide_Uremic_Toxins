# NUMPY 2.x COMPATIBILITY NOTE
# -----------------------------
# np.trapz was deprecated in NumPy 2.0 (replaced by np.trapezoid) and
# REMOVED ENTIRELY in later NumPy 2.x releases. Every script in this
# package that performs AUC/trapezoidal integration already uses a
# version-safe wrapper:
#
#     def _trapz(y, x):
#         if hasattr(np, "trapezoid"):
#             return np.trapezoid(y, x)
#         return np.trapz(y, x)
#
# so this codebase works correctly on both old and new NumPy. If you
# add new analysis scripts, use the same pattern rather than calling
# np.trapz directly — a bare np.trapz call (or the unsafe
# getattr(np, "trapezoid", np.trapz) pattern, which evaluates the
# np.trapz default eagerly and crashes anyway) will raise
# AttributeError on NumPy >= ~2.2.
#
# scipy.integrate.solve_ivp (the Radau-method ODE solver used in
# src/simulation.py) requires scipy >= 1.4; any reasonably recent
# scipy 1.x release works.
#
